# elearning-platform-redesign-
Learnly — E-Learning Platform Redesign
A responsive front-end concept for a modern online learning dashboard.
Project objective
Redesign an e-learning platform to improve navigation, onboarding, progress tracking, and multimedia course discovery.
Features
Responsive dashboard for desktop and mobile
Course cards with progress bars and lesson details
Search/filter for courses
Weekly schedule and learning-goal visualization
Navigation states and interactive feedback messages
Simple, friendly visual hierarchy
Tech stack
HTML5
CSS3
Vanilla JavaScript
Run locally
Download or clone this repository.
Open index.html in any modern browser.
No installation or build tools required.
Note
This is a front-end prototype. Course actions and navigation use demo feedback; there is no backend, login system, or saved user data.
Portfolio summary
Learnly is a learner-first dashboard concept designed to make online education easier to navigate. The redesign focuses on clear course progress, quick access to ongoing lessons, weekly learning goals, and a responsive interface.
